# 🎨 Obys Agency – Interactive Web Design Portfolio

A modern, interactive, and visually striking portfolio website inspired by **Obys Agency** — a creative design studio known for bold and unique digital experiences. This project replicates the high-end feel of Obys’ site with smooth animations, rich media interactions, and a minimal aesthetic.

---

## 🚀 Live Demo

https://tarunkashyap03.github.io/Obys-agency/

---

## ✨ Features

* 🔄 **Smooth Scrolling** – Powered by *Locomotive Scroll* for a fluid user experience
* ⏳ **Animated Loader** – A preloader with percentage animation
* 🎥 **Custom Video Showcase** – In-page video player with interactive controls
* 🖼️ **Hover Gallery Effects** – Interactive image hover transitions via *Shery.js*
* ✍️ **Animated Typography** – Eye-catching text animations
* 📱 **Responsive Layout** – Optimized for all screen sizes
* 🖱️ **Custom Cursor** – Follows your movement with magnetic behavior

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3** – Advanced animations, flexbox, media queries
* **JavaScript (ES6+)**
* **GSAP** – Timeline-based animations
* **Locomotive Scroll** – Parallax and smooth scrolling
* **Shery.js** – Image and hover interactions
* **Three.js** *(Optional for future 3D elements)*

---

## 📦 Installation

Follow these steps to run the project locally:

```bash
# Clone the repository
https://github.com/TARUNKASHYAP03/Obys-agency

# Navigate to the project folder
cd obys-agency

# Open the project in your browser
start index.html  # or just double-click index.html
```

> ⚠️ No build tools or package managers required – it's fully static.
